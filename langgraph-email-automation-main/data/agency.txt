**完整的 AI Agent 平台**

Agentia 提供一套完整的功能，帮助你简化 AI Agent 的开发流程：

- **选择基础模型**：Agentia 深知选择合适基础模型的重要性，因此支持多种模型，包括所有 OpenAI 模型，以及 Llama3、Anthropic、Mistral 和 Gemini Pro 等开源或其他模型。你可以根据项目需求灵活选择技术栈，从而获得更好的性能和效果。

- **通过工具执行操作**：Agentia 可以无缝集成各种工具，例如通过 Bland.ai 实现语音通话，让 Agent 能够进行电话沟通；你也可以接入自己的工具，为 Agent 增加自定义操作能力，使其能够与各种平台和系统交互。

- **设计高质量 Prompt**：通过使用基于最新最佳实践的 Prompt 模板，提升 Agent 的表现。你还可以使用 Prompt 优化系统进行调整，帮助 Agent 与客户进行更有效的沟通。

- **通过版本管理实现零停机**：Agentia 支持你离线调整和优化 Assistant，然后平稳切换到线上版本，整个过程不会中断正在运行的 Agent 服务。

- **使用自己的数据进行训练**：你可以使用自己的数据集定制 Agent，并利用检索增强生成（RAG）技术实现更精准、更个性化的服务。

- **使用模板快速开发**：Agentia 提供多种预构建模板，你可以在模板基础上进行定制，大幅缩短开发时间。
